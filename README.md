## NebulaOS

A single-file browser operating system lives in [`index.html`](index.html) — a window manager, a
virtual filesystem, procedural wallpapers, twelve applications and two 3D games (an open-world
GTA-style sandbox and a first-person wave shooter) rendered with a hand-written WebGL engine, with
no dependencies or build step. Open the file in Chrome to boot it.

See [NEBULAOS.md](NEBULAOS.md) for the full documentation, including the special feature
(**Chronos**, an OS-wide time machine that can rewind the entire desktop — games included).
